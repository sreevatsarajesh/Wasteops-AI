# Dataset protocol

Primary supervised dataset: UCI RealWaste (4,752 images, nine classes, 524x524). It was collected at the point of reception in an operating landfill environment. UCI dataset ID 908: https://archive.ics.uci.edu/dataset/908/realwaste

The code maps the original folder labels to the stable API taxonomy. A deterministic stratified 80/10/10 image-level split is generated by the training script. This supports a reproducible baseline, but images from the same acquisition environment may share nuisance factors. A stronger research evaluation requires source/site-separated splits and an independently collected test set.

Do not use the RealWaste training score as evidence of real-world global performance. Document dataset version, hashes, split indices, software versions and all preprocessing for publication work.
